# AmbuTrack GitHub APK Builder

This is a small Android project configured to build an AmbuTrack debug APK using GitHub Actions.

## Build on GitHub
1. Upload the contents of this ZIP to the Ambu-track repository.
2. Open the **Actions** tab.
3. Select **Build AmbuTrack APK**.
4. Run the workflow with **Run workflow**.
5. When it finishes, download the **AmbuTrack-debug-apk** artifact.

This starter project provides the APK build pipeline and a simple AmbuTrack screen. App features can be added to `MainActivity.java` and the Android resources.
